Intruções de Execução e funcionalidades implementadas:

Abrir a preview do ficheiro tp4.qmd -> Inicialmente a página
abrirá no separador Dados, este separador tem 3 quadrados do
lado esquerdo com dados sobre o resultado das legislativas a
nível de Portugal continental.

À direita destes dados está o mapa de Portugal, colorido com
as cores (com baixa opacidade)do partido mais votado em cada
distrito. O mapa é interativo e está ligado à tabela à sua
direita em cima. Esta tabela mostra os resultados do distrito
selecionado. Começando com o número de inscritos e votantes
e seguido dos votos que cada partido obteve no mesmo.

Em baixo desta tabela está um input dropdown com os partidos
presentes nestas eleições, ao escolher um destes partidos
aparecerá a distribuição percentual dos seus votos por distrito
no gráfico de barras horizontal ordenado diretamente abaixo.

Se na barra superior selecionarmos agora o separador - Resultados
por Partido (Sunburst), mudamos para esta página que contém apenas
o gráfico circular do tipo Sunburst, também com a distribuição dos
votos de cada partido pelos distritos, embora aqui a percentagem
esteja omitida.

No terceiro e último separador (Dados Completos) é apresentada uma
versão extensa e completa dos dados importados para este trabalho,
desde os votos de cada partido em cada distrito, como a área do distrito
ou até o seu número de concelhos.
